# 02 — High-Frequency Slang & Expressions

:: ¿Qué pasa? :: What's up? / What's happening? | Example: ¿Qué pasa, amigo?
Pitfall: Not formal; use ¿Cómo está? for professional contexts.

:: ¡Qué bacán! / ¡Qué chévere! / ¡Qué guay! :: How cool! / Awesome! (regional: bacán = Chile/Peru, chévere = Caribbean/LatAm, guay = Spain). | Example: ¡Qué chévere el concierto!
Pitfall: Choose region-appropriate term; do not mix in formal writing.

:: Chinchín / ¡Salud! / ¡Chin chin! :: Cheers! / To your health! | Example: Chinchín, amigo.
Pitfall: Usually accompanied by eye contact; not for formal toasts (use Por tu salud in formal settings).

:: ¿Me entiendes? / ¿Me explico? :: You know? / Do you get me? | Example: Es complicado, ¿me entiendes?
Pitfall: Can sound slightly aggressive if tone is wrong; use with friends.

:: Está chido / Está padre / Está genial :: It's cool / It's great (regional: chido = Mexico, padre = Mexico, genial = universal). | Example: El diseño está chido.
Pitfall: Know your region; chido and padre are informal.

:: ¡Qué rollo! :: What a mess / What's up? (Mexico — can be negative or neutral depending on tone). | Example: ¡Qué rollo con el tráfico!
Pitfall: Context-dependent; can sound complaining.

:: Dar marcha / Dar paso / Dar luz verde :: To give the green light / To proceed / To start moving. | Example: Démosle paso al proyecto.
Pitfall: Idiomatic; do not translate literally.

:: Echar de menos / Extrañar :: To miss (someone/thing). Example: Extraño a mi familia. / Te echo de menos.
Pitfall: Extrañar takes indirect object (hispanic); echar de menos also works.

:: Meter la pata :: To put one's foot in one's mouth / To make a mistake. | Example: Metí la pata en la reunión.
Pitfall: Very colloquial; avoid in formal reports.

:: Tocar madera / Cruzar los dedos :: Knock on wood / Cross fingers. | Example: Toco madera para que salga bien.
Pitfall: Not literal action; cultural expression.

:: Tener buena onda / Mala onda :: To be in good/bad vibes / mood. | Example: Hoy tengo buena onda.
Pitfall: Onda can mean wave or vibe; context determines meaning.

:: Al tiro / De una :: Immediately / Quickly / All at once. | Example: Ven al tiro.
Pitfall: Very regional (Chile/Peru — al tiro). Use inmediatamente for universal.
