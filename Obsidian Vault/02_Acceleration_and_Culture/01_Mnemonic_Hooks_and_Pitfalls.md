# 01 — Mnemonic Hooks, Memory Tricks & Pitfalls

:: LONERS (Masculine gender shortcut) :: L-O-N-E-R-S (L, O, N, E, R, S endings are mostly masculine).
Examples: El libro, El coche, El tren, El coche, El actor, El mes. | Trap: Some LONERS are exceptions (el problema, el mapa, el clima — actually these end in A, so not LONERS).
Pitfall: Do not apply blindly; check -e nouns like la leche (feminine).

:: D-ÍA-Z-C-I-ÓN (Feminine gender shortcut) :: Words ending in -d, -ión, -z, -ción, -ión are mostly feminine.
Examples: La ciudad, La libertad, La canción, La televisión, La lección. | Trap: El avión, el camión end in -ión but are masculine.

:: DOCTOR (Ser mnemonic) :: Description, Occupation, Characteristic, Time, Origin, Relationship.
Examples: Es médico (Occupation). / Es de México (Origin). / Es inteligente (Characteristic). / Es la una (Time). / Es mi hermano (Relationship).
Pitfall: Never confuse with PLACE (ESTAR).

:: PLACE (Estar mnemonic) :: Position, Location, Action, Condition, Emotion.
Examples: Estoy cansado (Condition). / Estoy en casa (Location). / Estoy comiendo (Action — progressive). / Estoy triste (Emotion). / Estoy sentado (Position).
Pitfall: Even permanent physical descriptions can sometimes use estar (estoy enfermo — temporary state).

:: Gender Exceptions (Must Memorize) :: El agua (f, but takes el), La mano (f, ends in -o), El día (m, ends in -a), El mapa (m, -a), El problema (m, -a), La clase (f, -e), El coche (m, -e — actually coche is masculine, yes LONERS applies).

:: False Friend — Embarazada :: "Pregnant" (NOT embarrassed). Embarrassed = avergonzado/a. Example: Estoy embarazada. (I'm pregnant).
Pitfall: Very common confusion in conversation; always clarify context.

:: False Friend — Éxito :: "Success" (NOT exit). Exit = salida. Example: El éxito fue grande. (The success was big).
Pitfall: In spoken Spanish, éxito is pronounced with stress on second syllable; don't confuse with exit (exit is pronounced similarly but different word).

:: False Friend — Constipado :: "Having a cold / congested" (NOT constipated). Constipated = estreñido. Example: Estoy constipado. (I have a cold / I'm congested).
Pitfall: Medical context confusion; always specify síntomas if needed.

:: False Friend — Soportar :: "To tolerate / endure" (NOT to support). To support = apoyar / sostener. Example: No puedo soportar el ruido. (I can't tolerate the noise).
Pitfall: In formal writing, avoid using soportar for support.

:: False Friend — Ropa :: "Clothing / clothes" (NOT rope). Rope = cuerda / soga. Example: Mi ropa es nueva. (My clothes are new).
Pitfall: Common beginner mistake due to similar spelling.

? Subjunctive Trigger — WEIRDO (Wishes) :: Quiero que... / Deseo que... / Ojalá que... / Espero que... (all trigger present subjunctive).
Answer: Present Subjunctive. | Full: Quiero que él estudie. / Ojalá que venga. | Note: Ojalá often stands alone (Ojalá llueva) but uses subjunctive.
Pitfall: Positive belief verbs (sé que, creo que in affirmative) use indicative; only negative/doubt versions (no creo que, dudo que) use subjunctive.
