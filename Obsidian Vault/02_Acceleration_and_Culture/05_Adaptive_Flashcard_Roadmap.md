# 05 — Adaptive Flashcard Roadmap (Milestone-Gated)

> [!abstract] Milestone-gated CEFR mastery system linked to vault `#flashcards/*` decks.

---

> [!info] How to Use This Roadmap
> Each Phase defines target competency, card quotas, assigned deck tags, and a gatekeeper diagnostic (`?` format). Pass the diagnostic with 80%+ accuracy before unlocking the next level's full deck.

## Phase 1: A1 Foundations & Present Tense Mechanics

### Target Competency
Introduce yourself, ask basic questions, describe your surroundings, express identity with *Ser* vs. *Estar*, count, and use present tense correctly.

### Assigned Deck Tags
- `#flashcards/grammar/a1`
- `#flashcards/vocab/a1`
- `#flashcards/drills/stem-changing-radicals`

### Daily Quota
15 new cards + all due reviews (~20 min/day).

### Diagnostic Gatekeeper Cards (`?` format)

? A1 Gatekeeper 1 — Present + Ser/Estar: Complete the sentences using the correct form of *ser* or *estar* and the correct present conjugation.
```
Yo ______ (ser) estudiante. Mi hermano ______ (estar) cansado hoy. Nosotros ______ (vivir) en Madrid. Ella ______ (pensar — e->ie) mucho.
```
`soy / está / vivimos / piensa | Pass if all 4 correct.`

? A1 Gatekeeper 2 — Gender Agreement: Provide the correct article and adjective agreement.
```
El libro (nuevo) → ______ libro ______
La casa (rojo) → ______ casa ______
```
`el libro nuevo / la casa roja | Pass if agreement is exact.`

? A1 Gatekeeper 3 — Basic Direct Object: Replace the noun with the correct direct pronoun.
```
Veo el libro → _____ veo.
Compro las manzanas → _____ compro.
```
`lo / las | Pass if pronouns match gender/number.`

> - [ ] Pass A1 Gatekeeper 3 (Direct Object)

## Phase 2: A2 Narrative Control & Past Tense Mastery

### Target Competency
Describe past experiences (Preterite), describe past habits/backgrounds (Imperfect), use reflexive routines, navigate shopping/travel, and combine direct + indirect pronouns.

### Assigned Deck Tags
- `#flashcards/grammar/a2`
- `#flashcards/vocab/a2`
- `#flashcards/drills/preterito-indefinido-irregulars`

### Daily Quota
20 new cards + all due reviews (~30 min/day).

### Diagnostic Gatekeeper Cards (`?` format)

? A2 Gatekeeper 1 — Preterite vs. Imperfect Contrast: Identify whether each sentence needs Preterite (completed action) or Imperfect (habit/description) and provide the correct conjugation.
```
Cuando yo ______ (ser — habit/background) niño, ______ (jugar — habit) al fútbol. Ayer yo ______ (ir — completed) al parque y ______ (ver — completed) a mi amigo.
```
`era / jugaba / fui / vi | Pass if tense selection and conjugation are perfect.`

? A2 Gatekeeper 2 — Reflexive Routine + Past: Conjugate reflexive verbs correctly in the past with correct pronoun placement.
```
Ayer me ______ (despertar — e->ie, reflexive, pret) temprano. Normalmente me ______ (vestir — reflexive, imperfect) rápido.
```
`desperté / vestía | Note: despertarse → me desperté (preterite, no stem change in nosotros).`

? A2 Gatekeeper 3 — Direct + Indirect Combined (`le/les -> se`): Provide the combined pronoun replacement.
```
Le di el libro → ______ ______ ______ (indirect + direct replacement + verb past).
Les entregué las cartas → ______ ______ ______.
```
`Se lo di / Se las entregué | Pass if se substitution and order are exact.`

## Phase 3: B1 Mood Shift & Subjunctive Mastery

### Target Competency
Express opinions, doubts, wishes, hypothetical situations, and future plans using Present and Imperfect Subjunctive, verbal periphrases, and relative pronouns.

### Assigned Deck Tags
- `#flashcards/grammar/b1`
- `#flashcards/vocab/b1`
- `#flashcards/drills/subjunctive-triggers-and-forms`

### Daily Quota
20 new cards + all due reviews (~35 min/day).

### Diagnostic Gatekeeper Cards (`?` format)

? B1 Gatekeeper 1 — Subjunctive Trigger Recognition (`WEIRDOS`): Complete the clause with the correct mood (Subjunctive) triggered by `es importante que`, `dudo que`, `es posible que`.
```
Dudo que ella ______ (venir — pres subj). Es importante que nosotros ______ (trabajar — pres subj) juntos. Es posible que ______ (llover — pres subj) mañana.
```
`venga / trabajemos / llueva | Pass if all use subjunctive.`

? B1 Gatekeeper 2 — Imperfect Subjunctive Derivation: Derive the correct imperfect subjunctive stem from the preterite 3rd person plural.
```
Si yo ______ (tener — tuv-) más dinero... / Aunque ______ (hacer — hicieron) tarde, salimos.
```
`tuviera / hiciera | Note: tuv- and hic- stems derived from tuvieron/hicieron.`

? B1 Gatekeeper 3 — Future/Conditional & Periphrases: Provide future or conditional form + verbal periphrases.
```
Mañana ______ (ir — future simple) al cine. Si tuviera dinero, ______ (comprar — conditional) una casa. Llevo ______ (trabajar — gerundio, periphrasis) 5 años.
```
`iré / compraría / trabajando | Pass if future/conditional/periphrasis forms exact.`

> [!check] Phase 3 Milestones
> - [ ] Pass B1 Gatekeeper 1 (Subjunctive Trigger Selection)
> - [ ] Pass B1 Gatekeeper 2 (Imperfect Subjunctive Derivation)
> - [ ] Pass B1 Gatekeeper 3 (Future/Conditional + Periphrases)
> - [ ] Complete B1 Vocabulary (Environment, Work, Opinion, Expressions_Connectors)

## Phase 4: B2 Fluency, Nuance & Discourse Control

### Target Competency
Debate complex topics, understand native-speed expressions, write structured essays, control advanced prepositions (`por` vs. `para`), and use complex conditional sentences.

### Assigned Deck Tags
- `#flashcards/grammar/b2`
- `#flashcards/vocab/b2`
- `#flashcards/slang`
- `#flashcards/acceleration`

### Daily Quota
15 new cards + mixed daily reviews (~30 min/day). Rotate through `#flashcards/slang` and `#flashcards/acceleration` twice per week.

### Diagnostic Gatekeeper Cards (`?` format)

? B2 Gatekeeper 1 — Complex Subjunctive / Adverbial Clauses: Select correct mode with `aunque`, `en cuanto`, `mientras`, `a no ser que` based on reality vs. unreality.
```
Aunque ______ (llover — subj/ind?) mañana, saldremos. / Aunque ______ (llover — ind, real), salimos hoy. / En cuanto ______ (llegar — subj/ind?) ella, empezamos. / A no ser que ______ (venir — subj) pronto, cancelaremos.
```
`llueva / llueva (future unreality) / llueve / llegue / venga | Pass if mode selection matches context.`

? B2 Gatekeeper 2 — Type 2 & 3 Conditionals + Passive Voice: Complete complex sentences.
```
Si yo ______ (ser — pluperf subj) presidente... / El libro ______ (ser — ser passive) leído por muchos. / La información ______ (difundir — pasiva refleja) rápidamente.
```
`hubiera sido / es leído / se difunde | Pass if conditional type, passive ser, and pasiva refleja are correct.`

? B2 Gatekeeper 3 — Reported Speech & Formal Connectors: Convert direct to indirect speech and use formal discourse markers.
```
Directo: "Leeré el libro mañana." → Indirecto (reported past): Él dijo que ______ (leer — conditional/past future) ______.

Use connectors: ______ (sin embargo) / ______ (por lo tanto) / ______ (aunque + mode?) / ______ (de tal modo que).
```
`leería / leería el libro / sin embargo / por lo tanto / aunque sea difícil / de tal modo que | Pass if reported speech shift + connectors are exact.`
