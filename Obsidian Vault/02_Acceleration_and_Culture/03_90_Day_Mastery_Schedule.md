# 03 — 90-Day Mastery Schedule

:: Phase 1 (Days 1-30): Foundation — A1 Phase :: Daily 15-45 min: 10 A1 grammar cards + 10 vocab cards + 1 verb drill file (Stem Changing). Goal: Present tense automatic, gender agreement automatic.
Examples: A1/Present_Indicative_Regular.md, A1/Verbs_Category.md, 01_Stem_Changing_Radicals.md.

:: Phase 2 (Days 31-60): Narrative — A2 Phase :: Daily 45 min: A2 preterite vs. imperfect + A2 vocabulary + reflexive routine cards + 1 drill file (Preterite Irregulars). Goal: Past tense contrast automatic, reflexive pronouns automatic.
Examples: A2/Preterite_vs_Imperfect.md, A2/Nouns_Daily_Life.md, 02_Preterito_Indefinido_Irregulars.md.

:: Phase 3 (Days 61-75): Mood — B1 Phase :: Daily 45-60 min: B1 subjunctive formation + B1 vocabulary + applied cards + 1 drill file (Subjunctive Triggers). Goal: Subjunctive trigger selection automatic, future/conditional automatic.
Examples: B1/Present_Subjunctive_Triggers.md, B1/Verbal_Periphrases.md, 03_Subjunctive_Triggers_and_Forms.md.

:: Phase 4 (Days 76-90): Fluency — B2 Phase :: Daily 60-90 min: B2 complex clauses + B2 formal vocabulary + advanced passive/reported speech + all 3 drill files rotated. Goal: Complex sentence construction automatic, formal register comfortable.
Examples: B2/Subjunctive_Indicative_Complex.md, B2/Passive_Voice.md, B2/Advanced_Connectors.md.
