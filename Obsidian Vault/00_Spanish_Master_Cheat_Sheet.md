## Subjunctive Forms (Quick)

### Present Subjunctive (Regular & Key Irregulars)
- **Regular:** Drop -o from yo-present, add opposite: hablar → hable / hablemos; comer → coma / comamos; vivir → viva / vivamos.
- **Key irregulars:** ser → sea / seamos; ir → vaya / vayan; tener → tenga / tengan; hacer → haga / hagan; saber → sepa / sepan; dar → dé / den; ver → vea / vean; ir → vaya.

### Imperfect Subjunctive (Derivation)
- Take 3rd person plural preterite, drop -on, add -a / -as / -a / -amos / -ais / -an.
- **Examples:** tener → tuvieron → tuviera / tuvieras; hacer → hicieron → hiciera; ser → fueron → fuera; ir → fueron → fuera; poder → pudieron → pudiera.

## 🧠 Essential Memory Frameworks

### Ser vs. Estar — DOCTOR vs. PLACE
| Ser (DOCTOR) | Estar (PLACE) |
|---|---|
| **D**escription (tall, beautiful) | **P**osition (seated, standing) |
| **O**ccupation (doctor, student) | **L**ocation (in/at/on) |
| **C**haracteristic (kind, intelligent) | **A**ction (in progress — gerundio) |
| **T**ime (hour, date, year) | **C**ondition (tired, sick, happy) |
| **O**rigin (from Spain, Mexican) | **E**motion (sad, excited, angry) |
| **R**elationship (brother, friend) | — |

### Gender Shortcuts
- **Masculine (LONERS):** L, O, N, E, R, S endings mostly masculine.
  Examples: el libro, el coche, el tren, el actor, el mes.
  Exceptions: el mapa, el día, el problema, el clima.
- **Feminine (D-ÍA-Z-C-IÓN):** D, ÍA, Z, C, IÓN endings mostly feminine.
  Examples: la ciudad, la libertad, la canción, la televisión, la nación.
  Exceptions: el avión, el camión.
- **Top 10 Exceptions (memorize):** el agua (f, takes el), la mano (f, ends -o), el mapa (m, ends -a), el día (m, ends -a), el problema (m, ends -a), la clase (f, ends -e), el coche (m, ends -e), la leche (f, ends -e), el hombre (m, ends -e).

### Por vs. Para — Quick Pick
| Por (Cause/Means/Duration/Agent) | Para (Destination/Goal/Deadline/Opinion) |
|---|---|
| Por amor / Por teléfono / Por una hora / Por el doctor / Por Madrid | Para ti / Para mañana / Para aprender / Para mí / Para la fiesta |
| Por = through, by, because of, during, per | Para = for (intent/purpose), to (goal), by (time) |

## 📌 Pronoun Order & Position Rules

### Order (When Combined)
**Reflexive → Indirect → Direct = R.I.D.**
Example: Me lo dice (me = indirect/reflexive context, lo = direct) — actually standard: Indirect first, then Direct, with se substitution.

### The Se Substitution
When indirect = le/les and direct = lo/la/los/las: **se replaces le/les**, direct stays.
- Le lo di → **Se lo di** (I gave it to him/her).
- Les las entregué → **Se las entregué** (I delivered them to them).

### Position
- **Before conjugated verb:** Me lo dio. / Se las entregué.
- **Attached to infinitive:** Quiero darlo / Quiero dárselo.
- **Attached to gerund:** Estoy dándole / Estoy dándole a él.
- **Attached to affirmative imperative:** Dime / Dime la verdad / Díselo (tell it to him/her).
- **Before negative imperative:** No me digas / No se lo digas.

## 🔗 Connectors & Transitions (B1/B2)

### Additive / Contrast / Cause / Result
- **Additive:** Además, También, Igualmente, Por un lado / Por otro lado
- **Contrast:** Aunque + subj/ind (real = ind; unreal = subj), Sin embargo, No obstante, A pesar de que, Mientras (while — ind if simultaneous real), En cambio
- **Cause:** Porque, Como (cause, not like), Puesto que, Dado que, A causa de, Debido a
- **Result:** Por lo tanto, Por consiguiente, Así que, De modo que, En consecuencia
- **Condition / Hypothetical:** Si + present → future (real); Si + imp subj → conditional (hypothetical present); Si + pluperf subj → perfect cond (unreal past)
- **Time / Sequence:** Cuando + ind (past completed), Cuando + subj (future), En cuanto + subj (future event), Mientras + ind (simultaneous), Antes de que + subj
- **Concessive:** Aunque + ind (fact); Aunque + subj (hypothetical/unreal); Aun cuando; Aunque sea difícil
- **Formal essay openers:** En primer lugar, Por una parte, Es evidente que, Desde mi punto de vista
- **Formal closers:** En conclusión, Para concluir, Por tanto, De este modo

## Grammatical Formulas (One-Line)

- **Ser = identity/permanent:** Yo soy / Tú eres / Él es / Nosotros somos / Ellos son
- **Estar = location/state/temporary:** Estoy / Estás / Está / Estamos / Están
- **Preterite = completed:** Ayer comí / Comiste / Comió / Comimos / Comieron
- **Imperfect = habit/description:** Cuando era niño / Era / Estábamos / Viían / Comía
- **Present Subjunctive = trigger word + opposite ending:** Que yo hable / Que tú comas / Que él vaya / Que nosotros tengamos
- **Imperfect Subjunctive = 3pl preterite -on + -a:** Tuviera / Hiciera / Fuera
- **Future = infinitive + endings:** Hablaré / Comerás / Vivirá
- **Conditional = infinitive + -ía:** Habría / Comerías / Viviría
- **Perfect = haber + pp:** He hablado / Ha comido / Hemos vivido
- **Passive (ser + pp):** La casa fue construida / El libro es leído
- **Pasiva Refleja (se + 3rd):** Se habla / Se venden
- **Reported Speech shift:** Pres → Imp / Imp → Pret / Future → Cond / Subj stays subj (with tense shift back when main is past)
