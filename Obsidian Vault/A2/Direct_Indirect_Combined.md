# A2 — Direct & Indirect Object Pronouns Combined (Se Substitution)

:: What is the order when both direct (DO) and indirect (IO) pronouns appear together? :: IO + DO: "se" is used for le/les before lo/la/los/las. Example: Se lo doy.
Examples: Se lo digo (I say it to him/her/them). / Se las entrego (I deliver them to him/her/them).
Pitfall: The substitution rule: le/les + lo/la/los/las becomes se + lo/la/los/las. Always.

? How do you say "I want to tell it to her" using pronouns?
Answer: Se lo quiero contar (IO + DO + infinitive) — or Quiero contárselo.
Examples: Se lo digo. / Se lo digo a María? No need to say both pronoun + name. Just se lo digo.
Pitfall: Se can confuse; remember it replaces le/les before direct pronoun.

:: Give the full table of direct + indirect pronouns. :: Direct: me/te/lo/la/nos/os/los/las. Indirect: me/te/le/nos/os/les. Combined: me lo / te lo / se lo / nos lo / os lo / se los / se las, etc.
Examples: Me lo dio. / Se las vendieron.
Pitfall: You always use se for third person indirect pronouns in combination; never use "le lo" or "les los".
