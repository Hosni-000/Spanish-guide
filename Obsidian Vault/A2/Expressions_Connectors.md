# A2 — Expressions, Connectors & Collocations

:: ¿Dónde está...? / ¿Cómo llego a...? / ¿Cuánto cuesta? :: Where is...? / How do I get to...? / How much does it cost? | Example: ¿Dónde está la estación? / ¿Cómo llego al aeropuerto?

:: Me gustaría... / Quiero + inf / Prefiero + inf :: I would like... / I want to... / I prefer to... | Example: Me gustaría viajar. Quiero ir al cine.

:: Hace + time (ago) / Desde hace / Desde + time :: Make past expressions. Example: Hace dos días fui al parque. / Vivo aquí desde 2010.

:: En total / En general / En cambio / Por ejemplo / Por eso / Por lo tanto :: In total / In general / On the other hand / For example / For that reason / Therefore | Example: En total, es barato. / Por eso no voy.

:: De repente / De vez en cuando / Una vez / A veces / Casi nunca :: Suddenly / From time to time / Once / Sometimes / Almost never | Example: De repente llovió.

:: A pesar de + noun/inf / Aunque + subj/indic / Sin embargo :: Despite / Although / However | Example: A pesar de la lluvia, salimos. / Aunque llueva, voy.

:: ¿Te gustaría...? / ¿Quisieras...? / ¿Podrías...? :: Would you like...? (polite) / Would you? (polite) / Could you? | Example: ¿Podrías ayudarme?

? Apply past expressions + preterite with A2 routine: "I went to the market yesterday; I bought bread and milk."?
Answer: Ayer fui al mercado. Compré pan y leche. | Grammar: preterite for completed past events; time expression "ayer" triggers preterite; direct objects included (pan, leche).
