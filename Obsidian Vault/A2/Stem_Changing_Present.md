# A2 — Stem-Changing Present (e→ie, o→ue, e→i)

:: Which vowels change in stem-changing verbs and when? :: Change occurs in all forms EXCEPT nosotros/vosotros (1st/2nd plural): e→ie, o→ue, e→i.
Examples: Quiero (quiero) vs queremos; Puedo vs podemos; Pido vs pedimos.
Pitfall: Remember nosotros/vosotros stay with original stem; do not change in plural.

? Give full conjugation of PENSAR (to think) — e→ie.
Answer: Pienso / piensas / piensa / pensamos / pensáis / piensan.
Examples: Yo pienso mucho. / Ellos piensan en el futuro.
Pitfall: The change applies to stressed syllable; do not apply to unstressed.

:: Conjugate ENCONTRAR (o→ue) fully. :: Encuentro / encuentras / encuentra / encontramos / encontráis / encuentran.
Examples: Encuentro el libro. / Nosotros encontramos una solución.
Pitfall: Find a safe mnemonic: o→ue is common with contar, dormir, morir, poder.

? How does e→i work in verbs like PEDIR (to ask for)? :: Pido / pides / pide / pedimos / pedís / piden.
Examples: Ella pide ayuda. / Nosotros pedimos café.
Pitfall: Only a few verbs have e→i; common ones: pedir, servir, repetir.
