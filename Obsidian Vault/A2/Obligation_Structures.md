# A2 — Obligation Structures (tener que, deber, hay que)

:: How do you expressobligation using TENER + QUE? :: Tú tienes que... / El/Ella tiene que... / Nosotros tenéis que...
Examples: Yo tengo que estudiar. / El niño tiene que dormirse.
Pitfall: Take掉 the que dropped; do not use the incorrect form ten-e-que.

? What does DEBER mean and how use it with infinitive?
Answer: DEBER (shall/should/must) + infinitive: Tú debes... / Ello debe...
Examples: Tú debes llamar. / Él debe terminar el trabajo.
Pitfall: Debe/debes singular agrees with number, not person.

:: How does HAY QUE differ from DEBER? :: HAY QUE is impersonal "there is/must" — third person singular always. You cannot conjugate it across persons except in Spain with hubiera/hubieras/hubiera etc.
Examples: Hay que lavarse las manos. / Hay que estudiar todos los días.
Pitfall: When clear subject = you, use TENER QUE or DEBER.
