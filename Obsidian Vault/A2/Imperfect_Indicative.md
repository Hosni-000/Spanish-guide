# A2 — Imperfect Indicative (Imperfecto)

:: How is -ar imperfect formed? :: Drop -ar, add -aba, -abas, -aba, -ábamos, -abais, -aban.
Examples: Yo hablaba con ella. / Nosotros viajábamos a veces.
Pitfall: Only three truly irregular imperfect verbs: ser (era, eras, era, éramos, erais, eran), ir (iba, ibas, iba, íbamos, ibais, iban), ver (veía, veías, veía, veíamos, veíais, veían).

? How do -er and -ir imperfect verbs form?
Answer: Drop -er/-ir, add -ía, -ías, -ía, -íamos, -íais, -ían.
Examples: Yo comía frutas. / Ellos vivían en Madrid.
Pitfall: The -er/-ir imperfect endings are identical; context distinguishes meaning.

:: Give full imperfect of SER, IR, and VER. :: SER: era / eras / era / éramos / erais / eran. IR: iba / ibas / iba / íbamos / ibais / iban. VER: veía / veías / veía / veíamos / veíais / veían.
Examples: Era un buen día. / Íbamos al parque. / Veía la televisión.
Pitfall: Remember accents on veía/veíamos/veis? No accent on veía in modern rules? Actually veía, veías, veía; veíamos, veíais, veían. The accent is needed on -ía.
