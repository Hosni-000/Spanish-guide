# A2 — Adjectives & Adverbs (Descriptions, Weather, Routine)

:: cansado / cansada (adj) :: tired | Example: Estoy cansado hoy. / Estoy cansada después de trabajar.

:: enfermo / enferma (adj) :: sick | Example: Estoy enferma hoy. (I'm sick today)

:: ocupado / ocupada (adj) :: busy / occupied | Example: El baño está ocupado. (The bathroom is occupied)

:: temprano / tarde (adv) :: early / late | Example: Llego temprano. / Llego tarde.

:: rápido / lentamente (adv) :: quickly / slowly | Example: Camino rápidamente. / Hablo lentamente.

:: siempre / nunca / a veces (adv) :: always / never / sometimes | Example: Siempre estudio. / Nunca duermo tarde.

:: mucho / poco / demasiado / bastante (adv) :: a lot / little / too much / quite a lot | Example: Como mucho. / Trabaja bastante.

:: soleado / nublado / lluvioso / nevado (adj) :: sunny / cloudy / rainy / snowy | Example: El día está soleado. / Está nublado hoy.

:: cómodo / incómodo (adj) :: comfortable / uncomfortable | Example: La silla es cómoda. / Estoy incómodo.

:: barato / caro (adj) :: cheap / expensive | Example: El hotel es barato. / El vuelo es caro.

:: viejo / nuevo (adj) :: old / new | Example: Mi maleta es vieja. / Mi camisa es nueva.

:: frío / caliente / templado (adj) :: cold / hot / warm | Example: El clima está templado. / La sopa está caliente.
