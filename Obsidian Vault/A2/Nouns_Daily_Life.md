# A2 — Nouns & Daily Life (Travel, Shopping, Health, Routine)

:: el aeropuerto (noun) :: airport | Example: El aeropuerto está lejos. (The airport is far)

:: el tren (noun) :: train | Example: El tren llega tarde. (The train arrives late)

:: el vuelo (noun) :: flight | Example: El vuelo es temprano. (The flight is early)

:: el hotel (noun) :: hotel | Example: El hotel es barato. (The hotel is cheap)

:: la maleta / la maleta de viaje :: suitcase / travel bag | Example: Mi maleta es pesada. (My suitcase is heavy)

:: la ropa (noun) :: clothes | Example: La ropa está limpia. (The clothes are clean)

:: el vestido / la falda / el pantalón / la camisa (noun) :: dress / skirt / pants / shirt | Example: El vestido es rojo.

:: el dinero (noun) :: money | Example: No tengo mucho dinero. (I don't have much money)

:: el precio (noun) :: price | Example: El precio es justo. (The price is fair)

:: la factura (noun) :: bill (restaurant/store) | Example: La factura es alta. (The bill is high)

:: el clima / el tiempo (noun) :: weather | Example: El clima está nublado. (The weather is cloudy)

:: el sol (noun) :: sun | Example: El sol brilla. (The sun shines)

:: la lluvia (noun) :: rain | Example: Hay lluvia hoy. (There's rain today)

:: la nieve (noun) :: snow | Example: La nieve es blanca. (The snow is white)

:: el cuerpo (noun) :: body | Example: Mi cuerpo está cansado. (My body is tired)

:: la cabeza / la mano / el pie / el ojo / la boca (noun) :: head / hand / foot / eye / mouth | Example: Me duele la cabeza. (My head hurts)

:: la cabeza / el cuerpo — combined health terms: :: dolor (noun) :: pain | Example: Tengo dolor de cabeza.

:: la enfermera (noun) :: nurse | Example: La enfermera ayuda al paciente.

:: el médico / la doctora (noun) :: doctor / female doctor | Example: El médico receta medicamentos.

:: la farmacia (noun) :: pharmacy | Example: La farmacia está abierta.

:: la receta (noun) :: prescription | Example: Tengo una receta médica.
