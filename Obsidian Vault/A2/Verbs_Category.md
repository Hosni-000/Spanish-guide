# A2 — Verbs by Category (Action, Routine, Health, Reflexive)

:: comprar (verb, regular -ar) :: to buy | Example: Compré una camisa. (I bought a shirt)

:: vender (verb, regular -er) :: to sell | Example: Venden ropa en la tienda. (They sell clothes in the store)

:: viajar (verb, regular -ar) :: to travel | Example: Viajamos al aeropuerto. (We travel to the airport)

:: reservar (verb, regular -ar) :: to reserve/book | Example: Reservamos un hotel. (We reserved a hotel)

:: llegar (verb, regular -ar) :: to arrive | Example: El tren llega tarde. (The train arrives late)

:: salir (verb, irregular — salgo, salí) :: to leave/go out | Example: Salí temprano. (I left early)

:: volver (verb, o→ue, irregular past: volví) :: to return | Example: Volví a casa. (I returned home)

:: perder (verb, e→ie; past: perdí) :: to lose / miss | Example: Perdí mi maleta. (I lost my suitcase)

:: doler (verb, o→ue — me duele) :: to hurt / ache | Example: Me duele la cabeza. (My head hurts me — literally: head hurts me)

:: despertarse (verb, reflexive — stem-changing e→ie) :: to wake up (oneself) | Example: Me despierto temprano. (I wake up early)

:: vestirse (verb, reflexive — e→i) :: to dress/get dressed | Example: Me visto rápido. (I get dressed quickly)

:: ducharse (verb, reflexive — regular) :: to shower/take a shower | Example: Me ducho por la mañana. (I shower in the morning)

:: acostarse (verb, reflexive — o→ue) :: to go to bed | Example: Me acuesto tarde. (I go to bed late)

:: sentirse (verb, reflexive — e→i) :: to feel (emotion/state) | Example: Me siento cansado. (I feel tired)

:: enfermarse (verb, reflexive — regular) :: to get sick | Example: Me enfermé ayer. (I got sick yesterday)

:: cuidar (verb, regular -ar) :: to take care of | Example: Cuido a mi hermano. (I take care of my brother)
