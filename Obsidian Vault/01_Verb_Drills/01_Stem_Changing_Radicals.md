# 01 — Stem Changing Radicals (e->ie, o->ue, e->i)

:: Pensar | Yo (Presente) :: pienso
:: Pensar | Tú (Presente) :: piensas
:: Entender | Él (Presente) :: entiende
:: Contar | Nosotros (Presente) :: contamos (no stem change in nosotros)
:: Dormir | Ellos (Presente — o->ue) :: duermen
:: Volver | Ella (Presente — o->ue) :: vuelve
:: Pedir | Yo (Presente — e->i) :: pido
:: Pedir | Nosotros (Presente) :: pedimos (no change in nosotros)
:: Servir | Tú (Presente) :: sirves
:: Jugar | Él (Presente — u->ue) :: juega
:: Preferir | Nosotros (Presente — e->ie) :: preferimos
:: Pensar | Yo + contexto: Yo (pensar) en mi futuro. :: pienso | Yo pienso en mi futuro.
:: Dormir | Nosotros (dormir) ocho horas. :: dormimos | Nosotros dormimos ocho horas.
:: Preferir | Tú (preferir) café o té. :: prefieres | Tú prefieres café o té.

? Ella (dormir — o->ue) ocho horas cada noche.?
duerme | Full: Ella duerme ocho horas cada noche. | Stem: dormir → duerme (3rd sg present, o→ue).

? Nosotros (pedir — e->i) un café.?
pedimos | Full: Nosotros pedimos un café. | Stem: pedir → pedimos (1st pl, no change).

? Ellos (volver — o->ue) mañana temprano.?
vuelven | Full: Ellos vuelven mañana temprano. | Note: volver is o→ue.
