# 02 — Pretérito Indefinido Irregular Stems

:: Tener | U-Stem: Yo (Pretérito) :: tuve
:: Tener | Tú (Pretérito) :: tuviste
:: Estar | U-Stem: Él (Pretérito) :: estuvo
:: Poder | U-Stem: Nosotros (Pretérito) :: pudimos
:: Poner | U-Stem: Yo (Pretérito) :: puse
:: Saber | U-Stem: Ellos (Pretérito) :: supieron
:: Hacer | I-Stem: Yo (Pretérito) :: hice
:: Hacer | Él (Pretérito) :: hizo
:: Querer | I-Stem: Nosotros (Pretérito) :: quisimos
:: Venir | I-Stem: Tú (Pretérito) :: viniste
:: Decir | J-Stem: Yo (Pretérito) :: dije
:: Decir | Ellos (Pretérito) :: dijeron
:: Traer | J-Stem: Él (Pretérito) :: trajo
:: Conducir | J-Stem: Nosotros (Pretérito) :: condujimos
:: Ir / Ser | Totally Irregular: Yo (Pretérito) :: fui
:: Dar | Totally Irregular: Él (Pretérito) :: dio
:: Ver | Totally Irregular: Nosotros (Pretérito) :: vimos
:: Andar | U-Stem: Tú (Pretérito) :: anduviste

? Tuvimos (tener — U-Stem) — translate and conjugate 3rd pl past.?
tuvimos (nosotros) / Ellos tuvieron | Full: Tuvimos problemas. / Ellos tuvieron éxito. | Stem: tuv- (3rd pl: tuvieron — note accent? No; tuvieron without accent in modern rules? Actually tuvieron is correct).

? (Hacer — I-Stem) Yo _______ el trabajo ayer.?
hice | Full: Yo hice el trabajo ayer. | Note: hice (yo), hizo (él/ella), hicimos (nosotros), hicieron (ellos).

? (Decir — J-Stem) Ellos _______ la verdad.?
dijeron | Full: Ellos dijeron la verdad. | Stem: dij- + -ieron.
