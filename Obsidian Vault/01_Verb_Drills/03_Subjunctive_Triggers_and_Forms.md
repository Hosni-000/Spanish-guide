# 03 — Subjunctive Triggers & Conjugation Speed

:: Present Subjunctive — Regular -ar (hablar): Yo :: hable
:: Present Subjunctive — Regular -er (comer): Tú :: comas
:: Present Subjunctive — Regular -ir (vivir): Él :: viva
:: Present Subjunctive — Irregular: Ser (yo/él/nosotros) :: sea / sea / seamos
:: Present Subjunctive — Irregular: Ir (yo/ellos) :: vaya / vayan
:: Present Subjunctive — Irregular: Tener (yo/usted) :: tenga / tenga
:: Present Subjunctive — Irregular: Hacer (yo/ellos) :: haga / hagan
:: Present Subjunctive — Irregular: Saber (yo/ella) :: sepa / sepa
:: Present Subjunctive — Irregular: Dar (yo/usted) :: dé / dé (with accent)
:: Present Subjunctive — Irregular: Ver (yo/ellos) :: vea / vean
:: Imperfect Subjunctive — From preterite 3pl: Tener → tuvieron → tuviera / tuvieras / tuviera / tuviéramos / tuvierais / tuvieran
:: Imperfect Subjunctive — Hacer → hicieron → hiciera / hacer? Actually hiciera / hicieras / hiciera / hiciéramos / hicierais / hicieran
:: Imperfect Subjunctive — Ser → fueron → fuera / fueras / fuera / fuéramos / fuerais / fueran
:: Imperfect Subjunctive — Ir → fueron (same ser preterite 3pl) → fuera / etc.

? Trigger — „No creo que...“ + (Ella / Venir - Presente Subjuntivo)?
venga | Full: No creo que ella venga. | Mood: Present Subjunctive triggered by no creo (doubt/negation).

? Trigger — „Es importante que...“ + (Nosotros / Trabajar — Presente Subjuntivo)?
trabajemos | Full: Es importante que trabajemos juntos. | Trigger: Impersonal expression (es importante que) → subjunctive.

? Trigger — „Quiero que...“ + (Tú / Hacer — Presente Subjuntivo)?
hagas | Full: Quiero que tú hagas el trabajo. | Trigger: Wish/request (quiero que) → subjunctive.

? Imperfect Subjunctive derivation: Si (Yo / Tener — Imperfect Subjuntivo) más dinero...
tuviera | Full: Si tuviera más dinero, viajaría. | Derivation: tuvieron → tuviera; conditional paired.
