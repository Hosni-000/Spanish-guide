# B2 — Advanced Prepositional Nuances (Por vs. Para, Compounds)

:: When is POR used? :: Cause / reason (por hambre) / movement through / exchange / duration / means (por teléfono) / agent of passive / approximate place (por Madrid) / comparison / division.
Examples: Lo hice por amor. / Fue hecho por él. / Pagué 10 euros por el libro.
Pitfall: Do not confuse with para.

? When is PARA used?
Answer: Purpose / destination / recipient / comparison (for a certain standard) / time limit / opinion (para mí) / suitability.
Examples: Es para ti. / Estudio para aprobar. / Es para mañana.
Pitfall: Para = to/for someone or something; Por = by/through/reason/exchange.

:: Give compound prepositions (prepositional locutions): :: Dentro de / fuera de / alrededor de / al lado de / cerca de / lejos de / a pesar de / en vez de / a causa de / en lugar de.
Examples: A pesar de la lluvia, salimos. / En vez de estudiar, dormí.
Pitfall: They often take the article (de, en, a) as part of the phrase.
