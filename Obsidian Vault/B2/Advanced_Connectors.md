# B2 — Advanced Connectors & Discourse Markers (Argument / Essay Structure)

:: How do you start an argument/opinion essay? :: En primer lugar / Para empezar / Es evidente que / Desde mi punto de vista / A mi parecer.
Examples: En primer lugar, el problema es grave. / Desde mi punto de vista, la solución es clara.
Pitfall: These are not just vocabulary but structural; organize argument clearly.

? How do you present contrast and conclusion? :: Contrast: Sin embargo / No obstante / Aunque / A pesar de / Por otro lado. Conclusion: En conclusión / Para concluir / Por tanto / Por consiguiente / Así que / De este modo.
Examples: Aunque es difícil, debemos intentarlo. / Por consiguiente, es importante actuar rápido.
Pitfall: Ensure logical coherence: contrast markers should be followed by opposite idea; conclusion by summarizing.
