# B2 — Nouns & Daily Life (Politics, Society, Science, Formal/Abstract)

:: la política / el gobierno / el partido / la elección / el voto / la democracia (noun) :: politics / government / party / election / vote / democracy | Example: La política es compleja. / La democracia requiere participación.

:: la economía / el mercado / la inflación / el desempleo / la recesión (noun) :: economy / market / inflation / unemployment / recession | Example: La inflación aumenta. / El desempleo es alto.

:: la sociedad / la comunidad / la población / las generaciones (noun) :: society / community / population / generations | Example: La sociedad cambia rápidamente. (Society changes quickly)

:: la cultura / la tradición / la identidad / el patrimonio (noun) :: culture / tradition / identity / heritage | Example: La identidad cultural es importante.

:: la justicia / los derechos / la ley / la norma / la regulación (noun) :: justice / rights / law / rule / regulation | Example: Los derechos humanos son fundamentales.

:: la ciencia / la investigación / la teoría / el experimento / la evidencia (noun) :: science / research / theory / experiment / evidence | Example: La evidencia es clara.

:: la tecnología / la innovación / la digitalización / los datos / la inteligencia artificial (noun) :: technology / innovation / digitalization / data / artificial intelligence | Example: La inteligencia artificial transforma la sociedad.

:: el debate / la conferencia / el discurso / la presentación (noun) :: debate / conference / speech / presentation | Example: El discurso fue convincente.

:: la responsabilidad / la obligación / la obligación moral (noun) :: responsibility / obligation / moral obligation | Example: Tenemos la responsabilidad de actuar.

:: el conflicto / la crisis / la guerra / la paz / la reconciliación (noun) :: conflict / crisis / war / peace / reconciliation | Example: La guerra devastó la región.

:: la red / la red social / la comunicación global (noun) :: network / social network / global communication | Example: Las redes sociales conectan a personas.

:: la perspectiva / el punto de vista / la visión / la interpretación (noun) :: perspective / point of view / vision / interpretation | Example: Desde mi perspectiva, es injusto.
