# B2 — Conditional Sentences (Type 1 Real, Type 2 Hypothetical Present, Type 3 Unreal Past)

:: Type 1 (Real / Possible): Si + Present Indicative, ... Future / Present / Imperative? :: Yes, real conditions: Si estudio, aprobaré.
Examples: Si llueve mañana, no saldré. / Si me ayudas, lo haré.
Pitfall: The then-clause can also be imperative if instructing: Si tienes tiempo, llama.

? Type 2 (Hypothetical Present / Unreal): Si + Imperfect Subjunctive, ... Conditional.
Answer: Si tuviera dinero, compraría una casa.
Examples: Si fuera tú, lo haría. / Si lloviera ahora, no saldríamos.
Pitfall: Imperfect subjunctive always; do not use present subjunctive.

:: Type 3 (Unreal Past): Si + Pluperfect Subjunctive (had + past participle), ... Perfect Conditional (would have). :: Formed with hubiera/hubieras/hubiera + participle in if; habría + participle in then.
Examples: Si hubiera estudiado, habría aprobado. / Si me hubiera llamado, habría respondido.
Pitfall: Know both clauses; if only the past condition isn't met, both are unreal.
