# B2 — Passive Voice (Ser + Participio vs. Pasiva Refleja)

:: Passive with SER + past participle: How formed? :: Verb ser (in same tense) + past participle agreeing with subject; agent introduced by por.
Examples: El libro fue escrito por Cervantes. / La carta será entregada mañana.
Pitfall: Past participle must agree in gender/number with subject: El proyecto fue terminado (masc.); Las tareas fueron terminadas (fem. pl.).

? What is Pasiva Refleja (Se + 3rd person)? :: Used when agent is unknown/irrelevant; verb conjugated in 3rd person (sing/pl) and stays active form; subject receives action: Se vende casa / Se venden coches.
Examples: Se habla español aquí. / Se construyó un puente.
Pitfall: Pasiva reflexiva usually for intransitive/unknown agent; use ser + participio for explicit agent.
