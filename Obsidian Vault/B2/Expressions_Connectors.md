# B2 — Expressions, Connectors & Collocations (Formal / Argumentative)

:: En primer lugar / En segundo lugar / En tercer lugar / Finalmente / Por último / En conclusión / Para concluir :: First / Second / Third / Finally / Lastly / In conclusion / To conclude | Example: En primer lugar, es evidente. / En conclusión, debemos actuar.

:: Por un lado / Por otro lado / Desde un punto de vista / Desde otra perspectiva / Contrariamente / A diferencia de :: On one hand / On the other hand / From one point of view / From another perspective / Conversely / Unlike | Example: Por un lado, es eficiente. Por otro lado, es arriesgado.

:: Dado que / Puesto que / Ya que / Como / En cuanto a / Respecto a / En relación con :: Given that / Since / As / As for / Regarding / In relation to | Example: Dado que hay evidencia, concluimos que...

:: A pesar de que / Aunque / Si bien / No obstante / Sin embargo / Aun así / Por el contrario :: Although / Even though / While / However / Nevertheless / Even so / On the contrary | Example: Aunque es complejo, es posible.

:: Es decir / Es decir que / En otras palabras / De hecho / En realidad / De tal modo que / Con el objetivo de / Con la intención de :: That is / In other words / In fact / Actually / In such a way that / With the goal of / With the intention of | Example: Es decir, es fundamental.

:: En toda justicia / A modo de comparación / A título de ejemplo / A efectos de / Con fines de :: In all fairness / By way of comparison / As an example / For the purposes of / For the sake of | Example: A modo de ejemplo, analicemos una política concreta.
