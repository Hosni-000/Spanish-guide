# A1 — Adjectives & Adverbs (Descriptions, Colors, Size, Time)

:: grande / pequeño (adj) :: big / small | Example: La casa es grande. / El perro es pequeño.

:: alto / bajo (adj) :: tall / short (height) | Example: Mi hermano es alto. (My brother is tall)

:: bueno / malo (adj — irregular: buen/mal before noun) :: good / bad | Example: Es un buen libro. / Es un mal día.

:: bonito / feo (adj) :: beautiful / ugly | Example: El parque es bonito. / El coche es feo.

:: feliz / triste (adj) :: happy / sad | Example: Estoy feliz hoy. / Ella está triste.

:: rojo / azul / verde / amarillo (adj — colors agree) :: red / blue / green / yellow | Example: La manzana es roja. / El cielo es azul.

:: nuevo / viejo (adj) :: new / old | Example: El coche es nuevo. / El libro es viejo.

:: rápido / lento (adj) :: fast / slow | Example: El coche es rápido. / El niño camina lento.

:: caliente / frío (adj — state) :: hot / cold | Example: El café está caliente. / El agua está fría.

:: fácil / difícil (adj) :: easy / difficult | Example: El examen es fácil. / La tarea es difícil.

:: mucho / poco (adv / adj) :: a lot / little | Example: Tengo mucho trabajo. / Hay poco tiempo.
