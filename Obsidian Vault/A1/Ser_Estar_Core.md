# A1 — Ser vs. Estar Core Distinction

:: When is SER used? :: Identity / profession / nationality / origin / inherent characteristics / time / possession.
Examples: Yo soy profesor. / Ella es española. / Es mi libro.
Pitfall: SER is for things that do not change easily (professions, nationality, physical descriptions like tall, though sometimes estar for health changes).

? When is ESTAR used? :: Location / temporary state / emotion / condition / weather / action in progress (with gerundio at A2).
Examples: Estoy en casa. / Estoy feliz. / La leche está fría.
Pitfall: Even permanent-looking descriptions may use estar if they describe condition: está enfermo (he is sick) rather than es enfermo (he is a sick person by identity, though sometimes used).

:: What's the mnemonic DOCTOR vs PLACE? :: SER: Description, Occupation, Characteristic, Time, Origin, Relationship. ESTAR: Position, Location, Action, Condition, Emotion.
Examples: Es médico (DOCTOR). / Está cansado (PLACE-like state, though emotion).
Pitfall: Practice both with real situations to build intuition, not just memorize rules.

? Can SER and ESTAR both work with the same adjective?
Answer: Yes — the meaning changes (ser aburrido = boring; estar aburrido = bored).
Examples: El libro es aburrido. / Yo estoy aburrido hoy.
Pitfall: This is a classic trap for A2/B1 learners.
