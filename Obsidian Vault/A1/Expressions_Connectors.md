# A1 — Expressions, Connectors & Collocations

:: ¡Hola! / ¡Buenos días! / ¡Buenas tardes! / ¡Buenas noches! :: Hello! / Good morning! / Good afternoon/evening! / Good night! | Example: ¡Buenos días, profesor!

:: Por favor / Gracias / De nada :: Please / Thank you / You're welcome | Example: Gracias por el pan. De nada.

:: ¿Cómo estás? / Estoy bien / Estoy mal / Estoy cansado :: How are you? / I'm well / I'm bad / I'm tired

:: Me gusta... / No me gusta... :: I like... / I don't like... | Example: Me gusta el café. No me gusta el agua fría.

:: Tengo hambre / Tengo sed / Tengo frío / Tengo calor / Tengo miedo / Tengo sueño :: I'm hungry / I'm thirsty / I'm cold / I'm hot / I'm scared / I'm sleepy | Example: Tengo hambre, vamos a comer.

:: ¿Qué tal? / ¿Cómo te llamas? / Me llamo... / ¿De dónde eres? / Soy de... :: How's it going? / What's your name? / My name is... / Where are you from? / I'm from...

:: en / a / de / con / sin / para / por / con / entre / sobre :: in / to / of / with / without / for / through/by / with / between / on/about | Example: Estoy en casa. Voy a la tienda. Es de María. Vivo con mi hermano.

? Apply expressions + present tense of tener: "I'm hungry and tired" / "Thank you"? 
Answer: Tengo hambre y estoy cansado. Gracias. | Grammar: tener + noun for physical/emotional states (tengo hambre); estar for temporary condition; basic courtesy phrases.
