# A1 — Direct Object Pronouns Principles

:: What replaces direct objects? :: Use me/te/lo/la/nos/os/los/las before conjugated verb. Example: Veo el libro → Lo veo.
Examples: La veo. / Los veo. / Nos llaman.
Pitfall: Remember gender agreement (lo for masculine; la for feminine). Plural los/las.
