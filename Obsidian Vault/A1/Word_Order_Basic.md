# A1 — Basic Word Order (Syntax)

? What is standard Spanish word order? :: Subject + Verb + Object/Complement is flexible for emphasis, but usually SVO.
Examples: María lee el libro. / El libro lo lee María. / María lo lee (with pronoun).
Pitfall: Adjectives often follow nouns (el libro rojo) though some precede (bueno, nuevo for subjective quality).
