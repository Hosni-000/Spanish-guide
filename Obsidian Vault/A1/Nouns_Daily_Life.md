# A1 — Nouns & Daily Life (Family, Home, Food, City)

:: el padre / el papá (noun) :: father / dad | Example: Mi padre es médico. (My father is a doctor) | Pitfall: papá is familiar; padre is formal.

:: la madre / la mamá (noun) :: mother / mom | Example: Mi madre cocina hoy. (My mom cooks today)

:: el hermano (noun) :: brother | Example: Mi hermano estudia mucho. (My brother studies a lot)

:: la hermana (noun) :: sister | Example: Mi hermana es alta. (My sister is tall)

:: el niño / la niña (noun) :: boy / girl | Example: El niño juega en el parque. (The boy plays in the park)

:: el hombre (noun) :: man | Example: El hombre lee un libro. (The man reads a book)

:: la mujer (noun) :: woman | Example: La mujer trabaja en el banco. (The woman works at the bank)

:: la casa (noun, f) :: house / home | Example: Mi casa es grande. (My house is big)

:: el piso / el apartamento (noun) :: apartment / flat | Example: Vivimos en un piso. (We live in an apartment)

:: la cocina (noun, f) :: kitchen / cuisine | Example: La cocina está limpia. (The kitchen is clean)

:: el baño (noun) :: bathroom | Example: El baño está ocupado. (The bathroom is occupied)

:: el dormitorio / la habitación (noun) :: bedroom / room | Example: Mi habitación es pequeña. (My room is small)

:: la mesa (noun) :: table | Example: La mesa es de madera. (The table is made of wood)

:: la silla (noun) :: chair | Example: La silla es cómoda. (The chair is comfortable)

:: el pan (noun) :: bread | Example: El pan está caliente. (The bread is hot)

:: la leche (noun, f) :: milk | Example: Quiero leche, por favor. (I want milk, please)

:: el agua (noun, f — takes el) :: water | Example: El agua es fría. (The water is cold) | Pitfall: feminine noun with masculine article.

:: la manzana (noun) :: apple | Example: La manzana es roja. (The apple is red)

:: el café (noun) :: coffee | Example: Me gusta el café. (I like coffee)

:: la ciudad (noun) :: city | Example: La ciudad es grande. (The city is big)

:: el parque (noun) :: park | Example: El parque es bonito. (The park is nice)

:: la escuela / el colegio (noun) :: school | Example: Voy al colegio. (I go to school)

:: la tienda (noun) :: store / shop | Example: La tienda está cerrada. (The store is closed)

:: el mercado (noun) :: market | Example: El mercado es barato. (The market is cheap)

:: el trabajo (noun) :: work / job | Example: El trabajo es difícil. (The job is hard)

? Apply gender agreement with A1 nouns and articles: "The house is big" / "My brother studies"? 
Answer: La casa es grande. / Mi hermano estudia. | Grammar: gender agreement (feminine noun with feminine article; masculine noun with masculine article); possessive adjective agreement.

? Apply present tense of SER with A1 family nouns: "My father is a doctor" / "My mother is tall"? 
Answer: Mi padre es médico. / Mi madre es alta. | Grammar: ser for identity/profession; present indicative conjugation.
