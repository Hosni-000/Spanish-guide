# A1 — Verbs by Category (Action, Routine, Emotion)

:: hablar (verb, regular -ar) :: to speak / talk | Infinitive: hablar | Example: Yo hablo español. (I speak Spanish)

:: comer (verb, regular -er) :: to eat | Example: Nosotros comemos pan. (We eat bread)

:: vivir (verb, regular -ir) :: to live | Example: Ellos viven en la ciudad. (They live in the city)

:: trabajar (verb, regular -ar) :: to work | Example: Mi padre trabaja hoy. (My father works today)

:: estudiar (verb, regular -ar) :: to study | Example: Yo estudio en la escuela. (I study at school)

:: caminar (verb, regular -ar) :: to walk | Example: Caminamos al parque. (We walk to the park)

:: mirar (verb, regular -ar) :: to watch / look | Example: Ella mira la televisión. (She watches TV)

:: leer (verb, regular -er) :: to read | Example: Yo leo un libro. (I read a book)

:: escribir (verb, regular -ir) :: to write | Example: Escribo una carta. (I write a letter)

:: jugar (verb, regular -ar — stem-changing?) :: to play (games/sports) — actually regular | Example: El niño juega al fútbol. (The boy plays soccer)

:: dormir (verb, irregular — o→ue stem) :: to sleep | Example: Yo duermo en mi cama. (I sleep in my bed)

:: ver (verb, irregular present) :: to see / watch | Example: Veo a mi amigo. (I see my friend)

:: tener (verb, highly irregular) :: to have | Example: Tengo hambre. (I'm hungry — literally: I have hunger)

:: hacer (verb, highly irregular — hago) :: to do / make | Example: Hago la tarea. (I do homework)

:: ir (verb, highly irregular — voy) :: to go | Example: Voy a la tienda. (I'm going to the store)

:: ser (verb, highly irregular — soy/es) :: to be (identity/permanent) | Example: Soy estudiante. (I am a student)

:: estar (verb, highly irregular — estoy/está) :: to be (location/state) | Example: Estoy cansado. (I'm tired)

:: querer (verb, stem-changing e→ie) :: to want / love | Example: Quiero agua. (I want water)

:: gustar (verb, special structure: indirect object + gustar) :: to be pleasing (like) | Example: Me gusta la música. (Music is pleasing to me — literally)
