# A1 — Present Indicative Irregular (Ser, Estar, Ir, Tener, Hacer)

:: What is the complete present conjugation of SER (to be - identity)? :: Yo soy / tú eres / él es / nosotros somos / vosotros sois / ellos son.
Examples: Ella es médica. / Nosotros somos estudiantes.
Pitfall: No accent on soy/son; do not confuse with estar (state).

? What is the difference between SER and ESTAR at A1 level?
Answer: SER = identity/characteristics/origin (permanent); ESTAR = location/condition/state (temporary).
Examples: Él es italiano. (origin/identity) / Él está cansado. (temporary state) / El libro está en la mesa. (location)
Pitfall: Use está for emotions/conditions and es for professions/nationalities.

:: Give full present of ESTAR. :: Estoy / estás / está / estamos / estáis / están.
Examples: Estoy bien hoy. / Ellos están en casa.
Pitfall: Third person singular está has an accent; avoid estara.

? Conjugate IR (to go) fully in present.
Answer: Voy / vas / va / vamos / vais / van.
Examples: Voy al mercado. / Vamos al cine.
Pitfall: Vamos is both present (we go) and imperative (let's go); use context.

:: Conjugate TENER (to have) fully in present. :: Tengo / tienes / tiene / tenemos / tenéis / tienen.
Examples: Yo tengo doce años. / Ellos tienen una casa.
Pitfall: Teng- stem is irregular; do not use teno.

? What is the present of HACER (to do/make) fully?
Answer: Hago / haces / hace / hacemos / hacéis / hacen.
Examples: Ella hace ejercicios. / Nosotros hacemos pan.
Pitfall: Third person singular hace, not haca; yo hago changes c→g.
