# B1 — Present Subjunctive Triggers (WEIRDO in Practice)

:: When do Wishes trigger the subjunctive? :: When the main clause expresses a wish, request, or command directed toward another subject: Quiero que / Deseo que / Pido que / Ruego que / Sugiero que / Prefiero que / Es mejor que / Es necesario que / Es importante que / Es posible que / Es probable que / Es dudoso que.
Examples: Quiero que tú estudies. / Es posible que llueva.
Pitfall: If the main clause expresses a fact or certainty (es verdad que, sé que, creo que in positive), use indicative; only with negation or doubt (no creo que, dudo que) use subjunctive.

? How does Emotions trigger the subjunctive?
Answer: Main clause expresses feeling/state about another's action/state: Me alegra que / Me entristece que / Me sorprende que / Me enoja que / Me gusta que / Me molesta que / Siento que / Estoy contento de que.
Examples: Me alegra que hayas ganado. / Estoy triste de que no puedas venir.
Pitfall: If emotion reacts to a fact rather than an unreality: Me alegra que ganaste (if fact, sometimes acceptable in Spain but standard is subjunctive for unreality/want).
