# B1 — Verbal Periphrases (Llevar + gerundio, Dejar de + inf, Acabar de + inf)

:: What does LLEVAR + gerundio mean? :: Duration from past to present: "Llevo / Llevas / Lleva / Llevamos / Lleváis / Llevan + gerundio." = I have been ... (continuous).
Examples: Llevo estudiando diez años. / Llevan viviendo aquí desde 2016.
Pitfall: It expresses how long an action has been occurring up to now.

? How does ACABAR DE + infinitive work?
Answer: Past near action just completed: Acabo / Acabas / Acaba / Acabamos / Acabáis / Acaban + de + inf. = I just (verb).
Examples: Acabo de comer. / Acabamos de llegar.
Pitfall: Do not confuse with haber; acabar de indicates immediate past.

:: What does DEJAR DE + infinitive mean? :: To stop/cease doing something.
Examples: Dejo de fumar. / Dejaré de trabajar pronto.
Pitfall: Not to confuse with dejar que (to allow); dejar de = to stop.
