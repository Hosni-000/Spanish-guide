# B1 — Verbs by Category (Communication, Emotion, Movement, Change, State)

:: explicar / explicar (verb, regular -ar) :: to explain | Example: Explico el problema. (I explain the problem)

:: discutir / argumentar (verb, regular -ar) :: to discuss / argue | Example: Discutimos la idea. (We discuss the idea)

:: expresar / comunicar (verb, regular -ar) :: to express / communicate | Example: Expreso mis sentimientos. (I express my feelings)

:: convencer / persuadir (verb, regular -ar / -ir) :: to convince / persuade | Example: Lo convengo de la verdad. (I convince him of the truth)

:: aprobar / rechazar (verb, regular -ar) :: to approve / reject | Example: Aprobé el proyecto. (I approved the project)

:: mejorar / empeorar (verb, regular -ar) :: to improve / worsen | Example: La situación empeora. (The situation worsens)

:: aumentar / disminuir (verb, regular -ar) :: to increase / decrease | Example: La contaminación aumenta. / El empleo disminuye.

:: parecer / sen tar (verb, irregular / reflexive) :: to seem / to feel | Example: Parece difícil. / Me siento bien.

:: cambiar / transformar (verb, regular -ar) :: to change / transform | Example: El clima cambia. (The climate changes)

:: crecer / desarrollar (verb, regular / irregular) :: to grow / develop | Example: Crecemos rápidamente. / El país se desarrolla.

:: alcanzar / lograr / conseguir (verb, regular / irregular stem) :: to reach / achieve / obtain | Example: Logré mi objetivo. (I achieved my goal)

:: decidir / elegir (verb, regular / irregular — elijo) :: to decide / choose | Example: Elijo este camino. (I choose this path)

:: recordar / olvidar (verb, regular / regular — forget) :: to remember / forget | Example: Recuerdo el día. / Olvido la fecha.

:: permitir / prohibir (verb, regular / irregular — prohíbo) :: to allow / forbid | Example: La ley prohíbe fumar. (The law forbids smoking)

:: llevar + gerundio (periphrasis) :: to have been (doing) | Example: Llevo años estudiando. (I've been studying for years)

:: acabar de + inf (periphrasis) :: to have just (done) — also used with past: Acabo de terminar. (I just finished)

:: dejar de + inf (periphrasis) :: to stop (doing) | Example: Dejé de fumar. (I stopped smoking)
