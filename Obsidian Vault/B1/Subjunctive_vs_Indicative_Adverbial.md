# B1 — Subjunctive vs. Indicative in Adverbial Clauses

:: How do ADVERBIAL clauses trigger mode? :: Some trigger subjunctive (purpose, condition, future reference); others use indicative (factual/reality).
Examples with subjunctive: Antes de que (before) / Aunque (although, if unreal) / A menos que (unless) / Con tal de que (provided that) / En cuanto (as soon as) when future. Examples: Antes de que llegues, limpia. / Aunque sea tarde, vamos.
Pitfall: Aunque triggers indicative when stating a fact: Aunque es tarde, salimos (indicative) vs Aunque sea tarde, salimos (subjunctive, indicating hypothetical/unreal).
