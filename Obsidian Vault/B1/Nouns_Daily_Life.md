# B1 — Nouns & Daily Life (Environment, Work, Opinions, Abstract Concepts)

:: el medio ambiente / el entorno (noun) :: environment / setting | Example: Debemos cuidar el medio ambiente. (We must take care of the environment)

:: la contaminación (noun) :: pollution | Example: La contaminación es alta. (Pollution is high)

:: el cambio climático (noun) :: climate change | Example: El cambio climático afecta al mundo.

:: la empresa / la compañía (noun) :: company / firm | Example: Trabajo para una empresa grande.

:: el empleado / la empleada (noun) :: employee | Example: El empleado es responsable.

:: el jefe / la jefa (noun) :: boss / chief | Example: Mi jefa es estricta. (My boss is strict)

:: la profesión / la carrera (noun) :: profession / career | Example: Mi carrera es la medicina.

:: el salario / el sueldo (noun) :: salary / wage | Example: El salario es justo. (The salary is fair)

:: el empleo / el trabajo (noun) :: job / employment | Example: Tengo un empleo estable. (I have stable employment)

:: la entrevista / la reunión (noun) :: interview / meeting | Example: Tengo una entrevista mañana. (I have an interview tomorrow)

:: la opinión / la idea / el punto de vista (noun) :: opinion / idea / point of view | Example: Mi opinión es diferente. (My opinion is different)

:: la noticia / el artículo / el periódico (noun) :: news / article / newspaper | Example: Leo las noticias hoy. (I read the news today)

:: la política / la sociedad / la economía (noun) :: politics / society / economy | Example: La política es complicada.

:: la libertad / la justicia / la paz (noun) :: freedom / justice / peace | Example: La paz es importante.

:: el sentimiento / la emoción / la alegría (noun) :: feeling / emotion / joy | Example: Siento mucha alegría hoy.

:: el miedo / el orgullo / la vergüenza (noun) :: fear / pride / shame | Example: Tengo miedo del futuro. / Siento orgullo por mi trabajo.

:: la naturaleza / el paisaje / el río / la montaña (noun) :: nature / landscape / river / mountain | Example: La naturaleza es hermosa. / El río es largo.

:: la tecnología / el internet / la computadora (noun) :: technology / internet / computer | Example: Uso la computadora todos los días.
