# B1 — Present Subjunctive: Formation & WEIRDO Triggers

:: How is the present subjunctive formed? :: For regular verbs: start with yo form, drop -o, add opposite ending: -ar → -e/emos/en; -er → -a/amos/an; -ir → -a/amos/an. For irregulars: use same irregular stem (tenga, sea, vaya, dé, esté, etc.).
Examples: Que yo viva / Que él sea / Que nosotros tengamos / Que ellos den / Que usted esté.
Pitfall: Some -ar verbs drop the -o and take -e; some irregulars change stem (e.g., dar → dé, ver → vea, ir → vaya, saber → sepa, haber → haya, tener → tenga).

:: What does WEIRDO stand for? :: Wishes (quiero que), Emotions (me alegra que), Impersonal (es importante que), Requests (pido que, aconsejo que), Doubt/Negation (no creo que, dudo que), Ojalá (Ojalá que, espero que).
Examples: Espero que vengas. / Es necesario que trabajemos.
Pitfall: Remember that the subjunctive only applies to the dependent clause triggered by a main clause; the trigger word determines mode.
