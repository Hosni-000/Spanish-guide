# B1 — Adjectives & Adverbs (Abstract, Emotion, Opinion, Environment)

:: importante / esencial / fundamental (adj) :: important / essential / fundamental | Example: Es importante cuidar el ambiente. (It's important to take care of the environment)

:: complejo / complicado (adj) :: complex / complicated | Example: El problema es complejo. (The problem is complex)

:: posible / probable / imposible / improbable (adj) :: possible / probable / impossible / improbable | Example: Es posible que gane. (It's possible he wins)

:: justo / injusto / equitativo (adj) :: fair / unfair / equitable | Example: Es injusto el salario. (The salary is unfair)

:: eficiente / ineficiente / productivo (adj) :: efficient / inefficient / productive | Example: El trabajo es productivo. (The work is productive)

:: responsable / irresponsable (adj) :: responsible / irresponsible | Example: Es un empleado responsable. (He's a responsible employee)

:: serio / serio (adj) :: serious | Example: Es un tema serio. (It's a serious topic)

:: abstracto / concreto (adj) :: abstract / concrete | Example: Es una idea abstracta.

:: racional / irracional (adj) :: rational / irrational | Example: Es una decisión racional.

:: emocional / racional (adj) :: emotional / rational | Example: Es una reacción emocional.

:: claramente / probablemente / posiblemente / quizás / tal vez (adv) :: clearly / probably / possibly / perhaps / maybe | Example: Probablemente llueva. (Probably it will rain)
