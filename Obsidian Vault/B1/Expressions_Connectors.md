# B1 — Expressions, Connectors & Collocations

:: Es evidente que / Es claro que / Es verdad que / Es falso que / Es obvio que / Es increíble que :: It's evident that / It's clear that / It's true that / It's false that / It's obvious that / It's incredible that | Example: Es evidente que necesitamos cambio.

:: Por esta razón / Debido a / A causa de / Gracias a / A pesar de / En cambio / Sin embargo / Por lo tanto / Por consiguiente / De hecho / En realidad / Según / De acuerdo con :: Because of / Thanks to / Despite / However / Therefore / In reality / According to / In agreement with | Example: Debido a la lluvia, cancelamos. / Según mi opinión, es justo.

:: Además / También / Igualmente / Por otro lado / Por una parte... por otra parte... / En primer lugar... en segundo lugar... / A modo de ejemplo / De tal manera que / Con el fin de / Para que + subj :: Furthermore / Also / Likewise / On the other hand / First... second... / By way of example / In such a way that / For the purpose of / So that | Example: Además, es importante. / Para que funcione, debemos trabajar.

:: Me parece que / Creo que / Opino que / Estoy convencido de que / Estoy de acuerdo con / Estoy en contra de / No estoy seguro de que / Dudo que / Es posible que / Es probable que / Es dudoso que :: I think that / I believe that / I'm convinced that / I agree with / I'm against / I'm not sure that / I doubt that / It's possible that / It's probable that / It's doubtful that | Example: Dudo que sea posible. / Estoy convencido de que es justo.

? Apply B1 opinion + subjunctive vocabulary: "I'm not sure it's possible; however, I believe it's probable."?
Answer: No estoy seguro de que sea posible. Sin embargo, creo que es probable. | Grammar: subjunctive (sea) after dudar/no estar seguro; indicative (es) after creer; connectors (sin embargo) linking contrasting ideas.
