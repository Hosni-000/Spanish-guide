#### The conjugation for **Comprar**
# COMPRAR
Yo => compr***o*** => we add **o**
Tú => compr***as*** => we add **a**
Usted, Él, Ella => compr***a*** => we add **a**
Nosotros=> compr***a+mos***=> we add **amos**
Ellos, Ellas, Ustedes=> compr***a+n***=> we add **n**

---
## The conjunctions of Vender

Yo => vend***o*** => we add **o**
Tú => vend***e+s*** => we add ***e*** + **s**
Usted, Él, Ella => vend***e*** 
Nosotros => vend***e+mos*** 
Ellos, Ellas, Ustedes => vend***e+n***

---
## The conjunctions of Vinir

Yo => viv**o** => we add **o**
Tú => viv**es** => we add **e** and **s**
Él, Ella, Usted => viv**e**
Nosotros => viv**i+mos** => we add **i** and **mos** 
Ellos, Ellas, Ustedes=> vivem**e+n** => we add **en**

# Hay / Hace / Hacer

| Word | Meaning | Arabic | Use when |
|---|---|---|---|
| **hay** | there is / there are | يوجد / هناك | something exists. Never changes. |
| **hacer** | to do / to make | يفعل / يصنع | base verb (dictionary form) |
| **hace** | he/she/it does | يفعل | someone does/makes something |
| **hace** (weather) | it is (hot/cold) | الجو | Hace frío = الجو بارد |
| **hace** (ago) | ago | منذ | Hace tres días = منذ ثلاثة أيام |

## Examples
- ¿Hay pizza? = هل يوجد بيتزا؟
- Hay tres libros. = يوجد ثلاثة كتب
- Hace calor. = الجو حار
- Hace frío. = الجو بارد
- Hace dos años. = منذ سنتين
- Ella hace la tarea. = هي تفعل الواجب
- Quiero hacer pizza. = أريد أن أصنع بيتزا

## Quick test
- Exists → **hay**
- Weather or "ago" → **hace**
- Someone does/makes → **hace**
- "to do/make" (base) → **hacer**

## Trap
- "Soy hay" is WRONG. hay = exists, no "who" inside it.
- "I am / this is me" → soy + yo → **Este soy yo**

# Este / Esta / Esto
- **este** = هذا (masculine, with noun): este libro
- **esta** = هذه (feminine, with noun): esta casa
- **esto** = هذا (no noun, just "this thing"): Esto es para mí
- This is me: **Este soy yo** (girl: Esta soy yo)

# Yo / Me / Mi / Mí
| Word | Arabic | Use when |
|---|---|---|
| **yo** | أنا | doing the action: Yo hablo |
| **me** | ـني | right before a verb: Me ayuda |
| **mi** | ـي (my) | before a noun, no accent: Mi casa |
| **mí** | لي | after para/a/de, accent: Para mí |

- Only difference between mi and mí = the accent.

# Other words
- dónde = where (NOT hay)
- tres = 3, dos = 2
- tarea = homework
- literalmente yo / me representa = li
